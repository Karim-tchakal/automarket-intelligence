# AutoMarket Intelligence

An automotive market data and price intelligence project focused on the Algerian used-car market.

## Overview

AutoMarket Intelligence aims to collect, organize, and analyze vehicle listings from [OuedKniss](https://www.ouedkniss.com/) to explore market trends and estimate used-car prices.

## Objectives

* **Data Collection:** Collect automotive listing data from [OuedKniss Cars & Vehicles](https://www.ouedkniss.com/automobiles).
* **Database:** Store and organize vehicle listings in a structured database.
* **Data Cleaning:** Handle missing prices, duplicate listings, inconsistent values, and unrealistic prices.
* **Market Analysis:** Explore used-car prices and market trends in Algeria.
* **Machine Learning:** Develop and evaluate models for used-car price estimation.

## Tech Stack

* **Language:** Python
* **Data Collection:** Web scraping and APIs
* **Database:** SQLite
* **Data Processing:** Pandas
* **Machine Learning:** Scikit-learn, CatBoost

## Project Status

🚧 In development.

## Data Pipeline

1. Collect vehicle listings from OuedKniss.
2. Store the original scraped data.
3. Clean, validate, and normalize vehicle information.
4. Prepare a structured dataset for analysis and model training.
5. Train and evaluate price prediction models.

## Data Management

Raw, intermediate, and processed datasets are kept separate to preserve the original data and make processing reproducible.
